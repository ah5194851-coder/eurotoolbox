Build a complete, production-ready website called **EuroToolBox**.

## 1. Website Concept

EuroToolBox is a free online tools website targeting users in Europe and worldwide.

Tagline:

**Free Online Tools for Everyday Life**

The website must be fast, modern, mobile-friendly, accessible, SEO-friendly, and suitable for deployment on **Cloudflare Pages** through GitHub.

Do NOT build a fake/demo website. Every tool that is implemented must actually work in the browser.

---

# 2. Technology Requirements

Prefer a lightweight architecture that can be deployed easily on Cloudflare Pages.

Use:

* HTML5
* CSS3
* JavaScript
* Modern responsive design
* No unnecessary backend
* Browser-side processing wherever technically possible
* No paid APIs
* No API keys required for the initial version

If using a framework, make sure the final project can be deployed to Cloudflare Pages and provide the exact build command and output directory in the README.

The website must NOT depend on Replit being online after deployment.

# 6. Implement Real Working Tools

Implement these tools as functional browser-based tools.

## PDF Tools

### PDF to Word

Allow the user to upload a PDF and convert/extract its text into a downloadable DOCX or editable document where technically possible.

Clearly explain limitations for scanned/image-only PDFs.

### Word to PDF

Allow users to create/download a PDF from supported text/document content.

### Merge PDF

Allow multiple PDF files to be uploaded and merged into one PDF.

### Split PDF

Allow users to select pages/ranges and create a new PDF.

### Compress PDF

Implement client-side compression where technically possible.

### JPG to PDF

Allow multiple images to be converted into a PDF.

### PDF to JPG

Convert PDF pages to downloadable images where technically possible.

Use reliable open-source browser libraries if needed. Do not use paid APIs.
